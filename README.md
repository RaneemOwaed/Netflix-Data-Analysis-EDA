# 🎬 Netflix Movies & TV Shows - Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs an Exploratory Data Analysis (EDA) on the Netflix dataset to uncover key trends in content distribution, top producing countries, and audience ratings.

## 🛠️ Tools & Libraries Used
* **Python**
* **Pandas** (Data cleaning and manipulation)
* **Matplotlib & Seaborn** (Data visualization)

## 📊 Key Findings & Insights
* **Content Type:** Movies represent the majority of Netflix's catalog compared to TV Shows.
* **Top Producers:** The United States and India are the leading countries in content production on the platform.
* **Target Audience:** The most common content ratings are **TV-MA** and **TV-14**, showing a strong focus on mature and young-adult audiences.

## 📂 Files in this Repository
* `Netflix_EDA_Analysis.ipynb`: The complete Jupyter Notebook containing the data cleaning code, visualizations, and outputs.
